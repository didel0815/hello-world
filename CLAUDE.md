## Development Workflow

### Branches

- `main` — stable, default branch
- Feature branches are merged via pull requests (e.g. `readme-edits`)

### Making Changes

Since there is no build system or test suite, the workflow is straightforward:

1. Create a feature branch from `main`
2. Edit files
3. Commit with a short, descriptive message
4. Push and open a pull request targeting `main`

### Commit Style

Commits in this repo use short, imperative-style messages:

```
Initial commit
Update README.md
VS Code
```

Keep commit messages brief and direct.

## Conventions
